系统已安装

如需重新安装，请删除项目目录下的 data/install.lock 后刷新本页面。 删除锁文件不会删除已有数据，重新安装时会覆盖 .env 与数据库配置。

运行环境检测

本项目为 Node.js + Express + SQLite 架构，不需要填写数据库账号密码（SQLite 是文件数据库）。 检测项等价于 PHP 项目的「扩展检测」：Node 版本、依赖模块、SQLite 扩展、目录权限与网络连通性。

站点与管理员账号

账号密码只写入服务器上的 .env 文件，不存入数据库，请务必修改默认值。

默认 8080，若被占用可改为 8081 等；修改后需要重启服务生效
定时任务按此时区执行，例如 Asia/Shanghai
相对项目根目录，默认 data/heartcron.db，不存在会自动创建
至少 8 位，建议字母 + 数字 + 符号
